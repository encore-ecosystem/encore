# Native CI repair

The first PR #199 native run converged and packaged all six targets, but exposed
61 compiler-test failures shared by Linux and Windows. Darwin's node preflight
stopped on one of the same visibility violations. EHIR's `compiler_api` and
`preparation_cache` tests also failed on every target.

The repair preserves the language's private declaring-type boundary. Lifetime
and ABI fixtures now explicitly publish methods called from free functions.
Standalone tests retain stable nominal/plugin ABI identities; their diagnostics
and generated future aliases use the source spelling of type owners. Disabled
`cfg` bodies are filtered before both body checks and lexical resolution. Core
prelude types bring their methods and enum constructors into the same semantic
scope. Selected imports retain an explicitly re-exported parent value when a
public namespace shares its name.

Generated coroutines now retain Context for each consuming child poll and drop
the parent's Context on both Pending and Ready. The regression covers multiple
nested immediate/pending awaits and confirms that the final waker ID is retired.
The minimal #200 program exits 1 with the original CI compiler and 0 with the
repaired candidate. Both dev and release async integration pass.

## Tooling costs

GDB showed full lint repeatedly scanning the complete token vector in
`identifier_occurrences`. One occurrence index per document now serves import,
local-variable and dead-code checks; the old scan remains the fallback when the
index cannot be allocated. Indexed counts have parity coverage, and actual CLI
lint warnings match the previous implementation. Full default project lint
completed with 133 warnings and no errors; no rules were disabled.

GDB also identified repeated UTF-8 prefix scans in formatter line splitting.
The replacement scans newline bytes once and copies whole UTF-8 line ranges,
preserving empty lines, CRLF, trailing CR and unterminated final lines. The
739,026-byte translator source formatted in 13.467 seconds with the repaired dev
candidate; the previous attempt was stopped after more than 18 minutes. This is
an observed complete run versus an interrupted run, not a precise speedup ratio.
A subsequent project format reported no changes, and `format --check` passed.

## Validation

All 61 original compiler failures passed locally after repair, together with the
new Context-retirement and cfg/prelude checks. Both original EHIR API/cache
failures passed. Project checking passed all 97 modules. Dedicated unit
contracts cover identifier-index parity, UTF-8 line boundaries and diagnostic
name rendering. The larger compiler suite and native platform checks remain
mandatory CI gates; see PR #199 for their current results.

Source formatting, semantic checking and default lint now run as separate steps
in a dedicated Linux job parallel to library/compiler tests. A formatting
failure still fails CI, while the other source checks remain visible. Compiler
convergence, target kits, library tests and release provenance checks are retained.

Confirmed defects: #200 (Context ownership), #201 (value/module namespace
selection), and #202 (formatter line-splitting complexity).
