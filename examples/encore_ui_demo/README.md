# Encore UI Demo

Build and run from this directory:

```sh
encore run
```

The demo is an interactive style gallery containing:

- primary, secondary, outline, danger, and ghost buttons;
- compact, regular, and large button sizing;
- status badges and bordered metric cards;
- toolbar, content sections, spacers, and a status bar;
- pointer hit testing with visible action feedback.

It requires an SDL3 runtime. Press Escape to exit.
